# Demo Chat Bot

A small Next.js chat-bot demonstration project for experimenting with conversational UI, application routing, and frontend integration.

## Technology

- Next.js
- React
- TypeScript / JavaScript

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Development

The main application UI can be developed through the Next.js `app/` structure. Keep API credentials and environment-specific configuration in `.env` files rather than source control.

## Project Goals

- Explore conversational interfaces
- Experiment with chat-oriented UI patterns
- Provide a lightweight foundation for connecting an AI backend

## Status

Development/demo project for chatbot experimentation.
